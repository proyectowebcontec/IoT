## 1. Objetivo

**Objetivo:**

Crear una versión preliminar del frontend y conectarla con el backend, validando en conjunto el flujo completo de datos del sistema: desde la adquisición de señales por el Arduino hasta su visualización final. Adicionalmente, iniciar la exploración del cableado del PLC Schneider para su futura integración.

---

## 2. Actividad realizada

1. Creación de una versión preliminar del frontend utilizando HTML, CSS y JavaScript, conectándolo con el backend.
2. Pruebas en vivo del flujo completo del sistema desarrollado hasta el momento:
   * El Arduino envía señales al gateway.
   * El gateway publica las señales al broker MQTT alojado en la EC2.
   * Un suscriptor al tópico correspondiente guarda los datos en MongoDB.
   * El backend consulta la base de datos y envía los resultados al frontend.
   * El frontend muestra la información de forma visual.
3. Conexión del PLC Schneider, con el fin de comprender el cableado correcto para su encendido.
