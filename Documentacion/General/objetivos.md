# Objetivos
## General
Diseñar, desarrollar y validar un prototipo de integración entre equipos industriales y Amazon Web Services, utilizando un Gateway industrial para la adquisición y transmisión segura de información desde el entorno operativo hacia la nube.

## Específicos
1. Investigar las tecnologías, protocolos y arquitecturas utilizadas para integrar sistemas industriales con plataformas IoT en la nube.
2. Analizar las características del equipo industrial, PLC, Gateway y servicios AWS disponibles.
3. Identificar las variables industriales que pueden ser adquiridas y transmitidas.
4. Diseñar la arquitectura de comunicación entre equipo industrial, PLC, Gateway, Internet y AWS.
5. Configurar y desarrollar los componentes de software necesarios para realizar la comunicación.
6. Implementar un prototipo funcional.
7. Realizar pruebas de comunicación, estabilidad, seguridad y pérdida de información.
8. Documentar los resultados, problemas encontrados, soluciones implementadas y conclusiones del proyecto.
